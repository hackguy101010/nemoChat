# Nemo Chat (Etappe 1)

Dieses Paket besteht aus nur 5 Dateien ohne Ordner. Die Oberfläche steckt in `worker.js`.

1. Neues **öffentliches** GitHub-Repository anlegen und diese 5 Dateien hochladen (Add file → Upload files).
2. Öffne `https://deploy.workers.cloudflare.com/?url=https://github.com/DEIN-NAME/DEIN-REPO` und folge den Schritten.
3. Trage `NVIDIA_API_KEY` und `APP_PASSWORD` ein und starte das Deployment.
4. Öffne die `…workers.dev`-Adresse, gib in den Einstellungen das Passwort ein und teste die Verbindung.

Installieren: Windows über das Installieren-Symbol in Edge/Chrome, Android über Chrome-Menü → „App installieren“.
Updates: neue `worker.js` im Repo hochladen, die alte wird überschrieben.
